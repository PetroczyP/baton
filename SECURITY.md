# Security policy

Report a vulnerability privately through GitHub's **Report a vulnerability** button on the [Security tab](https://github.com/PetroczyP/torch/security/advisories/new) of this repository. Please don't open a public issue for it.

You'll get a reply within seven days. A confirmed problem is fixed in a new release, and the advisory is published once the fix is available.

For anything that isn't a security issue, use [GitHub issues](https://github.com/PetroczyP/torch/issues).
